设置

访问密码

密码用于加密你的数据，修改后所有设备需用新密码解锁。忘记无法恢复。

GitHub 云同步

开启后，加密数据会自动同步到你的 GitHub 私有仓库，电脑/手机共用。不开启也能正常用本地版。

备份与迁移

导出会得到一份明文 JSON 备份（请妥善保存）；导入可恢复数据。

新手引导（GitHub 同步怎么弄）

  1. 注册免费 GitHub 账号：github.com/join
  2. 新建一个仓库（建议设为 Private），名字任取，如 personal-workbench
  3. 生成令牌：GitHub → Settings → Developer settings → Fine-grained tokens → 选你的仓库，权限勾 Contents: Read and Write
  4. 把用户名、仓库名、令牌粘到上方，点“保存设置”，再点“测试同步”
  5. 手机用浏览器打开你的 GitHub Pages 地址（仓库 Settings → Pages 开启），“添加到主屏幕”即可当 App
