# 个人工作台 · 使用说明（纯前端版，v2.3）

一个 **本地优先、跨设备、隐私安全** 的个人工作台，包含：

- **手机 App 端（C 端）**：年轻化移动界面，含看板、任务、笔记、知识库、我的。数据用你的访问密码端到端加密后存在浏览器本地，**可选**通过你自己的 GitHub 仓库开启云端同步。
- **管理台（B 端）**：桌面浏览器使用的**本地管理控制台**，与 C 端共用同一密码与同一份加密数据，提供数据概览、备份/恢复、GitHub 云同步、站点与模块配置、关于。
- **零后端、零构建**：整套产品不依赖任何服务器，纯静态文件即可部署到 GitHub Pages / Vercel / Nginx / 任意对象存储。

> 你的 C 端数据用**访问密码端到端加密**，密码不会离开浏览器；云同步时只有**密文**写入你的 GitHub 仓库，GitHub（和 PAT 令牌）都看不到明文。

## 一、C 端（手机 App）都有什么

| 模块 | 能干什么 |
|---|---|
| 看板 | 渐变 Hero 概览 + 子 tab（日历/图表/列表）：整合月历（任务蓝/笔记紫/习惯绿）+ 年度热力图 + 折线/环形/柱状多元图表 + 最近任务笔记 |
| 任务 | 表格化增/删/改/查，备注、搜索、按状态/标签筛选、设截止日 |
| 笔记 | Markdown 笔记，标签分类、保存网页链接、全文搜索 |
| 知识库 | 结构化知识卡片（标题+摘要+正文+分类+标签），搜索、一键复制 |
| 我的 | 个人中心 + **全部配置** + **GitHub 云端同步**：改密码、导出/导入、站点名与主题色（深浅可切换）、模块显隐/改名/排序、默认预设、看板布局 |

> 「我的」相当于「设置页 + 配置中心」的合体，所有改动即时生效并自动保存。

## 二、怎么打开 C 端（两种方式）

> ⚠️ 浏览器安全限制：直接双击 html 打开（`file://`）会禁用加密。请用下面任一方式。

### 方式 A：本地看（推荐先试）
1. 在这个文件夹里，地址栏输入 `cmd` 回车（Windows）。
2. 输入：`python -m http.server 8000` 回车。
3. 浏览器打开 `http://localhost:8000`。不用了在黑窗口按 `Ctrl+C` 关掉。

### 方式 B：部署上线（电脑手机都能用）
把站点静态文件（根目录的 html + `assets/` + `manifest.webmanifest` + `sw.js` + `icon.svg` + `admin/`）托管到任意静态服务。手机浏览器打开地址 → 「添加到主屏幕」即可像 App 使用（PWA，断网也能开）。

> **手机端能用哪些功能（部署前必读）**
> - **本地核心（任务 / 笔记 / 知识库 / 看板 / 我的配置）**：纯静态即可，数据加密存在手机浏览器本地，**完全可用**，离线也行。
> - **GitHub 云端同步**：依赖你提供的 GitHub PAT 与仓库（浏览器直连 `api.github.com`，需联网）。配置简单，详见第四节。

#### 推送到 GitHub 并开启 Pages（示例）
1. 在本机终端进入项目目录，先推送（本仓库已配好 `origin`）：
   ```bash
   git push -u origin master
   ```
   > 若本机无网络无法推送，可在你自己的电脑终端执行该命令。
2. 打开 `https://github.com/wjm-0112/workbench` → **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 **master** / 目录 **/ (root)** → Save。
3. 约 1 分钟后，手机浏览器打开 `https://wjm-0112.github.io/workbench/` → 菜单「添加到主屏幕」即可当 App 用。
   （仓库已含 `.nojekyll`，确保带 `_` 的文件不被 Jekyll 忽略。）

## 三、第一次使用 C 端

1. 打开后**设一个访问密码**（用来端到端加密你的数据）。
2. 请务必牢记这个密码——**忘记无法恢复**（加密数据打不开）。
3. 之后每次打开输入密码解锁即可。
4. 想跨设备？去「我的 → 云端同步（GitHub）」填写你的仓库信息，打开同步。

---

## 四、GitHub 云端同步（端到端加密）

> 这是 v2.1 的跨设备方案：**不需要任何后端**，数据加密后存放在**你自己的 GitHub 仓库文件**里。

1. 打开「我的」页 → 云端同步（GitHub）。
2. 在 GitHub 生成一个 Personal Access Token（PAT）：
   - **Fine-grained token**（推荐）：只对目标仓库授予 **Contents: Read and write** 权限。
   - **Classic token**：勾选 `repo` 权限。
   - 生成后**只显示一次**，请复制保存。
3. 填写：PAT、仓库所有者（owner）、仓库名（repo）、文件路径（path，默认 `sync/data.json`）。
4. 点「测试连接」验证仓库可达；点「上传（推送）」把加密 blob 推到仓库；点「下载（拉取）」把仓库密文合并回本地。
5. 另一台设备填**相同的 PAT + 仓库**，输入**同一访问密码**即可拉取解密，跨设备同步完成。

> 数据用访问密码在浏览器内 AES-GCM 加密后才写入仓库；PAT 只是传输凭证，GitHub 与你都只看到密文。请勿把 PAT 写进代码或公开仓库。

## 五、管理台（B 端）怎么用

管理台是**本地管理控制台**，与 C 端用同一密码、同一份加密数据，**不需要后端**。

1. 浏览器打开 `admin/login.html`（本地用 `http://localhost:8000/admin/login.html`；线上用 `<你的站点>/admin/login.html`）。
2. 输入**与 C 端相同的访问密码**解锁（首次即设置密码）。
3. 左侧导航：**数据概览 / 数据管理 / 站点配置 / 关于**，底部还有「工作台（C 端）」入口。
   - 数据概览：任务/笔记/知识库/习惯的统计卡 + 近 7 日趋势图 + 模块分布环形图 + **近 6 月财政收支柱状图**（Chart.js）。
   - 数据管理：导出/导入备份、GitHub 云同步（推送/拉取/测试）、危险区（清空本地数据）。
   - 站点配置：站点名称、深浅主题、模块显隐开关、**财政分类与财政账户预设**（写回同一份配置）。
   - 关于：版本号、技术栈说明、本地存储占用。

### 管理台 ⇄ C 端 无缝切换（v2.3 重点）
- 在 C 端「我的」页点「管理台」进入 B 端；在 B 端顶栏点「← 工作台」或左侧「工作台（C 端）」即可**免密返回 C 端**（两端共用同一会话密钥，无需重新输密码）。
- ⚠️ 只有点「退出」才会锁定并清除会话；日常在两端间穿梭请用上方「← 工作台」按钮，不要点「退出」。

### 管理台响应式侧栏（v2.3 重点）
- 桌面端：点顶栏左上角「☰」可把左侧栏**折叠成仅图标**的窄条，方便多看内容；再点一次展开。
- 手机端：左侧栏默认隐藏，点「☰」以**抽屉**形式滑出，点遮罩或导航项收起，适配小屏浏览。

## 六、备份（强烈建议）

- 「我的」页或管理台「数据管理」点「导出备份」，得到一份 `个人工作台备份.json`（**明文**，请自行保管）。
- 换设备/重装前，先导出一份保存好。
- 需要恢复时点「导入备份」选这个文件即可（会覆盖当前数据并刷新配置）。
- 跨设备最省事的方式是用第四节的 GitHub 云同步。

## 七、隐私说明

- 你的 C 端数据用**密码 AES 端到端加密**后存储/同步，密码不会离开你的浏览器，也不保存密码本身。
- 云同步时仓库只存密文；PAT 仅作 GitHub API 的传输凭证，本地不持久化明文令牌（会话级使用）。
- 所有配置（含云同步开关、主题色、模块设置）随数据整体加密，不再以明文留在浏览器。
