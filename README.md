# 个人工作台 · 使用说明（小白版，v2.0）

一个**本地优先、跨设备、隐私安全**的**双端产品**：

- **手机 App 端（C 端）**：年轻化移动界面，含看板、任务、笔记、知识库、**内容**、**商城**、我的。数据用你的密码加密存在本地，可选登录账号开启**云同步**。
- **管理系统端（B 端）**：专业后台，用来发布内容、管理用户/角色、看运营数据（桌面浏览器使用）。
- **后端服务**：真实 Node 服务，负责账号、内容、订单、云同步接口。

> 所有 C 端数据用你的**访问密码端到端加密**，后端只见密文；账号令牌只作传输凭证，隐私不泄露。

---

## 一、C 端（手机 App）都有什么

| 模块 | 能干什么 |
|---|---|
| 看板 | 一屏总览：待办/今日到期/逾期/习惯连续天数 + 近 7 日趋势 + 习惯打卡 |
| 内容 | 浏览/搜索/按分类筛选运营发布的文章，可收藏（Markdown 详情） |
| 任务 | 表格化增/删/改/查，备注、搜索、按状态/标签筛选、设截止日 |
| 知识库 | 结构化知识卡片（标题+摘要+正文+分类+标签），搜索、一键复制 |
| 商城 | 商品橱窗 → 购物车 → 模拟结算 → 我的订单（需登录账号） |
| 我的 | 个人中心 + **全部配置** + **账号云同步**：改密码、导出/导入、站点名与主题色（深浅可切换）、模块显隐/改名/排序、默认预设、看板布局 |

> 「我的」相当于原「设置页 + 配置中心」的合体，所有改动即时生效并自动保存。

## 二、怎么打开 C 端（两种方式）

> ⚠️ 浏览器安全限制：直接双击 html 打开（`file://`）会禁用加密。请用下面任一方式。

### 方式 A：本地看（推荐先试）
1. 在这个文件夹里，地址栏输入 `cmd` 回车（Windows）。
2. 输入：`python -m http.server 8000` 回车。
3. 浏览器打开 `http://localhost:8000`。不用了在黑窗口按 `Ctrl+C` 关掉。
4. （可选）先启动后端（见第五节），云同步/内容/商城才可用。

### 方式 B：部署上线（电脑手机都能用）
把站点静态文件（根目录的 html + assets + manifest + sw.js）托管到任意静态服务（GitHub Pages / Vercel / Nginx 等）。手机浏览器打开地址 → 「添加到主屏幕」即可像 App 使用（PWA，断网也能开）。

> ⚠️ **手机端能用哪些功能（部署前必读）**
> - **本地核心（任务 / 笔记 / 知识库 / 看板 / 我的配置）**：纯静态即可，数据加密存在手机浏览器本地，**完全可用**，离线也行。
> - **云同步 / 内容 / 商城**：依赖后端接口（当前写死**同源** `/api/*`）。GitHub Pages 这类**纯静态托管跑不了 Node 后端**，这三项在纯静态部署下不可用。
> - 若要手机端也能云同步 / 看内容 / 下单：① 把 `server/` 部署到能跑 Node 的公共主机；② 把 C 端接口基地址从「同源」改为该后端地址（`store.js` 里的 `/api` 前缀需参数化，属后续优化，暂未做）。

#### 推送到 GitHub 并开启 Pages（示例）
1. 在本机终端进入项目目录，先推送（本仓库已配好 `origin`）：
   ```bash
   git push -u origin master
   ```
2. 打开 `https://github.com/wjm-0112/workbench` → **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 **master** / 目录 **/ (root)** → Save。
3. 约 1 分钟后，手机浏览器打开 `https://wjm-0112.github.io/workbench/` → 菜单「添加到主屏幕」即可当 App 用。
   （仓库已含 `.nojekyll`，确保带 `_` 的文件与 SPA 不被 Jekyll 忽略。）

## 三、第一次使用 C 端

1. 打开后**设一个访问密码**（用来端到端加密你的数据）。
2. 请务必牢记这个密码——**忘记无法恢复**（加密数据打不开）。
3. 之后每次打开输入密码解锁即可。
4. 想跨设备？去「我的 → 云端同步（账号）」登录/注册账号，打开「启用云同步」。

---

## 四、账号云同步（替换原 GitHub 同步）

1. 打开「我的」页 → 云端同步（账号）。
2. 登录或注册一个账号（默认允许注册；可在 B 端关闭）。
3. 打开「启用云同步」开关。
4. 你的数据会用**访问密码**在浏览器内加密后上传到后端；另一台设备登录同一账号 + 输同一密码即可拉取解密合并。
5. 后端接口：`GET/PUT /api/sync/blob`（按用户存密文）。

> 不登录账号也能用「本地版」，数据存在当前浏览器里。

---

## 五、启动后端服务（B 端 + 同步/内容/商城所需）

```
cd server
npm install        # 安装 express jsonwebtoken bcryptjs（仅首次）
npm start          # 监听 http://localhost:3000
```
- 首次启动自动播种：管理员 `admin / admin123`、默认角色/租户、站点配置、4 篇演示内容。
- C 端目前**同源调用** `/api/*`（后端同进程托管前端时即 `localhost:3000`）。若把前端单独静态托管（如 GitHub Pages），需把 `server/` 部署为独立 Node 服务，并把 C 端接口基地址改为该后端地址（见第二节「手机端能用哪些功能」）。
- 后端静态托管守卫：`/server`、`/node_modules`、`.git` 返回 404，源码不泄露。

> 不启动后端：C 端本地功能（任务/笔记/知识库/看板/我的本地配置）照常可用；仅「内容/商城/云同步」需后端。

## 六、B 端（管理系统）怎么用

1. 先按第五节启动后端。
2. 浏览器打开 `http://localhost:3000/admin/login.html`，用 `admin / admin123` 登录。
3. 左侧导航：**看板 / 内容 / 用户权限 / 运维配置**。
   - 看板：运营统计 + 趋势图。
   - 内容：发布/编辑/下架文章（C 端「内容」模块读取已发布内容）。
   - 用户权限：用户、角色（权限）、租户管理（RBAC）。
   - 运维配置：站点配置、服务健康、审计日志。
4. 建议及时修改默认管理员密码（「我的」/B 端用户管理）。

## 七、备份（强烈建议）

- 「我的」页点「导出备份」，得到一份 `个人工作台备份.json`（**明文**，请自行保管）。
- 换设备/重装前，先导出一份保存好。
- 需要恢复时点「导入备份」选这个文件即可（会覆盖当前数据并刷新配置）。
- 后端数据：`server/data/` 目录即全部数据，整体备份该目录即可。

## 八、隐私说明

- 你的 C 端数据用**密码 AES 端到端加密**后存储/同步，密码不会离开你的浏览器，也不保存密码本身。
- 后端 `sync/blob` 只存密文；账号密码用 bcrypt 哈希，JWT 鉴权。
- 所有配置（含云同步开关、主题色、模块设置）随数据整体加密，不再以明文留在浏览器。

## 九、界面与主题

- **C 端**：年轻化移动 App 风，底部固定标签栏（看板/内容/任务/知识库/我的），卡片化；浅色/深色一键切换。
- **B 端**：专业后台风，桌面侧边栏 + 顶栏 + 表格；浅色/深色可切换。
- 站点名称、主题色、模块显隐与改名、默认预设、看板布局，都可在 C 端「我的」页网页端调整，无需改代码。

## 十、文件结构（以后想自己改也看得懂）

```
index.html / content.html / tasks.html / notes.html / snippets.html / orders.html / profile.html
                  C 端七大页面（手机 App 风）
admin/             B 端管理系统（login.html + index.html + assets）
assets/css/        tokens.css（设计令牌）+ style.css（C 端样式）+ admin.css（B 端样式）
assets/js/         store（数据+加密+同步+配置）、common（密码门/导航/主题）、
                   tasks/notes/snippets/dashboard/profile/content/orders（各页逻辑）
server/            Node/Express 后端（index/db/routes/middleware）
```
改文字、改颜色：C 端在 `assets/css/tokens.css`（令牌）+ `style.css`，配置在「我的」页；B 端在 `admin/assets/css/admin.css`。
