# 个人工作台 · 使用说明（小白版）

一个**本地优先、跨设备、隐私安全**的个人网站，做成**专业管理后台**的样子。包含：看板、任务、笔记、知识库、我的（个人中心 + 全部配置）。数据用你的密码加密后存在本地，可选同步到 GitHub 私有仓库。

---

## 一、这是什么

| 模块 | 能干什么 |
|---|---|
| 看板 | 一屏总览：待办/今日到期/逾期/习惯连续天数统计卡 + 近 7 日趋势 + 任务分布图 + 习惯打卡 |
| 任务 | 表格化增/删/改/查，多选批量操作、搜索、按状态/标签筛选、排序、设截止日 |
| 笔记 | 写笔记，加标签，详情页自动生成目录(TOC)、全文搜索高亮、标签筛选 |
| 知识库 | 结构化知识卡片（标题+摘要+正文+分类+标签），按分类/标签/全文搜索，一键复制 |
| 我的 | 个人中心 + **全部配置**：改密码、GitHub 同步、导出/导入、站点名与主题色（深浅可切换）、模块显隐/改名/排序、默认预设、看板布局 |

> 「我的」相当于原「设置页 + 配置中心」的合体，所有改动即时生效并自动保存。

---

## 二、怎么打开（两种方式）

> ⚠️ 因为浏览器安全限制，直接双击 html 文件打开时，加密功能会被禁用。请用下面任一方式。

### 方式 A：本地看（推荐先试）
1. 在这个文件夹里，地址栏输入 `cmd` 回车（Windows）。
2. 输入：`python -m http.server 8000` 回车。
3. 浏览器打开 `http://localhost:8000`。
4. 不用了就在那个黑窗口按 `Ctrl+C` 关掉。

> 没装 Python？百度“Windows 安装 Python”，一步步装好即可（勾选 “Add to PATH”）。

### 方式 B：部署到 GitHub Pages（电脑手机都能用，免费）

> 部署上去的是**网站代码**（已帮你准备好，本地仓库已建好）。你的笔记/任务在上传前会被密码加密，所以即使仓库公开也看不到明文。

**第 1 步：注册 GitHub（免费）**
- 打开 https://github.com ，点 Sign up，用邮箱注册一个账号。

**第 2 步：新建一个仓库（放网站代码）**
- 登录后点右上角「+」→ New repository。
- Repository name 填：`workbench`（或你喜欢的英文名，只能英文/数字/横线）。
- 选 **Public**（免费账号只能公开仓库；你的数据是加密的，安全）。
- 不要勾 “Add a README”，其它默认，点 Create repository。

**第 3 步：生成访问令牌（PAT，用来让你/我推送代码）**
- 打开 https://github.com/settings/tokens → Generate new token (classic)，Note 填 `workbench-deploy`，Expiration 选 `No expiration`（或 90 天）。
- 勾选 `repo`，最下面点 Generate token。**那串 `ghp_...` 只显示一次，立刻复制保存好。**

**第 4 步：把代码推上去（二选一）**
- 让我帮你推：把 `ghp_...` 令牌发我，我执行推送并开启 Pages（仅用于这一次命令，不写入任何文件）。
- 自己推（GitHub Desktop）：Add Local Repository 选中本文件夹 → Publish repository → 之后改完 Push。

**第 5 步：开启 Pages**
- 仓库 → Settings → Pages → Source 选 **Deploy from a branch**，Branch 选 **main**，文件夹 **/ (root)**，Save。
- 等 1～2 分钟，网址：`https://你的用户名.github.io/workbench/`。

**第 6 步：手机上像 App 一样用（华为手机也行）**
- 手机浏览器（华为自带浏览器或其他）打开上面的 Pages 网址。
- 点浏览器「菜单（⋯）」→ **「添加到主屏幕」** → 起个名字。桌面就多了一个图标，点开全屏、断网也能开（PWA）。

> 电脑和手机要**数据互通**，请再按下面「四、数据同步」在「我的」页配置同一个 GitHub 同步（建议用另一个私有仓库存加密数据）。只部署不配同步也能用，只是各自设备数据独立。

---

## 三、第一次使用

1. 打开后**设一个访问密码**（用来加密你的数据）。
2. 请务必牢记这个密码——**忘记无法恢复**（加密数据打不开）。
3. 之后每次打开输入密码解锁即可。

---

## 四、数据同步（可选）

1. 打开「我的」页 → 数据同步（GitHub）。
2. 勾选“启用云同步”，填 GitHub 用户名、仓库名、访问令牌（PAT）、数据文件路径（默认 `data.json`）。
3. 点「测试同步（推送）」：成功就说明通了；也可点「拉取同步」从仓库合并。改动会自动加密上传。
4. 另一台设备打开同一地址、输同一密码，即可拉取同步。

> 不配 GitHub 也能正常用「本地版」，数据存在当前浏览器里。

---

## 五、备份（强烈建议）

- 「我的」页点「导出备份」，得到一份 `个人工作台备份.json`（**明文**，请自行保管）。
- 换设备/重装前，先导出一份保存好。
- 需要恢复时点「导入备份」选这个文件即可（会覆盖当前数据并刷新配置）。

---

## 六、隐私说明

- 你的数据用**密码 AES 加密**后存储，密码不会离开你的浏览器，也不保存密码本身。
- 所有配置（含 GitHub 令牌、主题色、模块设置）也一并进入**加密存储**，不再以明文留在浏览器。
- GitHub 令牌只用于读写你自己的仓库；即使仓库被看到，没有密码也解不开密文。

---

## 七、界面与主题

- 专业管理后台风格：左侧固定导航 + 顶栏 + 内容区；手机端自动切换为顶栏 + 底部标签栏。
- 主色为深蓝/藏青；支持**浅色 / 深色一键切换**（顶栏太阳/月亮按钮，或「我的」里设置）。
- 站点名称、主题色、模块显隐与改名、默认预设、看板布局，都可在「我的」页网页端调整，无需改代码。

---

## 八、文件结构（以后想自己改也看得懂）

```
index.html      看板首页
tasks.html      任务
notes.html      笔记
snippets.html   知识库
profile.html    我的（个人中心 + 全部配置）
assets/css/style.css   样式（颜色/主题变量都在这里）
assets/js/store.js     数据 + 加密 + 同步 + 配置
assets/js/common.js    密码门 / 动态导航 / 双主题
assets/js/*.js         各页面逻辑（tasks/notes/snippets/dashboard/profile）
```
改文字、改颜色，基本都在 `style.css`（CSS 变量）和 `profile.html` + `assets/js/profile.js`（配置项）里。
